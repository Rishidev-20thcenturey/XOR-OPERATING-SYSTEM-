# XOR desktop theme — Aurora

XFCE defaults for every new user, staged into `/etc/skel/.config/xfce4/`
by the live-build hook. Aurora combines midnight glass, luminous teal,
Violet and restrained gold accents with Inter type, Arc-Dark widgets and
Papirus-Dark icons in the fallback XFCE session.

* `wallpapers/xor-royal-aurora.jpg` — default premium glass-ribbon aurora backdrop.
* `wallpapers/xor-midnight-x.png` and legacy `wallpaper.png` — deterministic
  alternate generated by `python3 tools/make_wallpaper.py`.
* `xor-logo.svg` — scalable glass-X identity used by the shell entries.
* `xfce4/xfconf/xfce-perchannel-xml/*.xml` — xsettings (theme/fonts),
  xfwm4 (window borders), xfce4-desktop (Royal Aurora backdrop).

The first-party panel/dock now lives in `desktop/xor_shell/` and autostarts
as an experience layer. XFCE's own panel remains configured as a fallback
until Aurora passes the on-desktop Milestone-2 gate; do not remove that
safety net merely to make an unverified screenshot cleaner.
